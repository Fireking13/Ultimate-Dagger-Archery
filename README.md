WIP video game I am making in Unreal Engine 5. The game is a first-person, fast-paced target shooting game where the player must collect as many points as possible within a limited time frame, using daggers that circle around the player and can be shot at targets. 

The points are calculated based on accuracy and how difficult of a shot it was, aka style, which includes air time, speed, and distance.

The game is inspired by Ultrakill, mostly its movement and techie things that the players can perform as they learn the game. I have currently made it so the daggers, once they hit a wall, become one-way platforms the player can stand on. This allows the player to have a lot more freedom when it comes to vertical movement and allows for more tech.
